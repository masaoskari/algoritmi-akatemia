# Listat

Listat ovat Pythonin tietorakenteita, jotka voivat sisältää useita arvoja. Ne ovat hyödyllisiä, kun haluamme tallentaa ja käsitellä useita liittyviä tietoja yhdessä paikassa. Listat kirjoitetaan hakasulkeiden `[]` sisään, ja niiden alkiot erotetaan pilkuilla. Esimerkiksi:

```python
lista = [1, 2, 3, 4, 5]
```
Tässä siis määritellään muuttuja `lista`, joka sisältää viisi kokonaislukua. Listat voivat sisältää myös muita tietotyyppejä, kuten merkkijonoja tai jopa muita listoja. 

Listan alkiot voidaan hakea indeksin avulla. Indeksit alkavat nollasta, joten ensimmäinen alkio on indeksissä 0, toinen alkio indeksissä 1, ja niin edelleen. Esimerkiksi:

```python
print(lista[0])  # Tulostaa 1
print(lista[2])  # Tulostaa 3
```

Listoihin voidaan lisätä uusia alkioita `append()`-metodilla:

```python
lista.append(6)
print(lista)  # Tulostaa [1, 2, 3, 4, 5, 6]
```
Voimme myös poistaa alkioita `remove()`-metodilla:

```python
lista.remove(3)
print(lista)  # Tulostaa [1, 2, 4, 5, 6], koska indeksin 3 alkio on poistettu
```
