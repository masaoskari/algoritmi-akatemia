# Lisää silmukoita

## For-silmukka

`for`-silmukka on toinen tapa kirjoittaa silmukka Pythonissa. Se on erityisen hyödyllinen, kun haluamme suorittaa tietyn koodilohkon tietyn määrän kertoja tai käydä läpi kaikki alkiot jossakin kokoelmassa, kuten listassa. `for`-silmukka kirjoitetaan seuraavasti:

```python
for i in range(5):
    # suoritettavat lauseet
```
Tässä `range(5)` luo sarjan lukuja 0, 1, 2, 3 ja 4. `for`-silmukka suoritetaan viisi kertaa, ja joka kerralla `i` saa arvon yhdestä näistä luvuista. Voimme käyttää `i`-muuttujaa silmukan sisällä, esimerkiksi:

```python
for i in range(5):
    print(i)
```
<EsimerkkiTulostus>
0
1
2
3
4
</EsimerkkiTulostus>

Tässä ohjelmassa `for`-silmukka käy läpi kaikki luvut 0:sta 4:ään ja tulostaa ne. 

`for`-silmukka on erittäin kätevä, kun haluamme käydä läpi kaikki alkiot jossakin kokoelmassa, kuten listassa. Esimerkiksi:

```python
lista = [10, 20, 30, 40, 50]
for luku in lista:
    print(luku)
```

<EsimerkkiTulostus>
10
20
30
40
50
</EsimerkkiTulostus>

Tässä ohjelmassa `for`-silmukka käy läpi kaikki alkiot listassa `lista` ja tulostaa ne.
